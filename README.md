# Disaster Relief Resource Management System

A web-based **Disaster Relief Resource Management System** designed to help organizations efficiently manage disaster-related resources, relief requests, shelters, vehicles, volunteers, and emergency operations from a centralized platform.

The system provides role-based authentication and a structured dashboard for monitoring disaster situations and coordinating relief activities. It enables users to manage resources, submit and track relief requests, maintain shelter and vehicle information, manage volunteers, generate statistical reports, and configure notification preferences.

## Key Features

*  Secure user registration and login
* Centralized disaster management dashboard
* Disaster creation, monitoring, and management
* Resource inventory and stock management
* Shelter management
*  Vehicle management
*  Volunteer management
*  Relief request creation and tracking
*  Reports and statistics
*  Notification preference management
*  Secure password handling
*  Form validation and basic security controls
*  Responsive web interface
*  Cloud deployment with Render and Aiven MySQL

## Technology Stack

* Frontend: HTML, CSS, JavaScript, Bootstrap
* Backend: Python, Flask
* Database: MySQL
* Database Hosting: Aiven
* Application Deployment: Render
* Version Control: Git & GitHub

## Purpose

The primary objective of this project is to provide a centralized and user-friendly platform that improves the organization, tracking, 
and coordination of disaster relief operations, helping relief teams manage critical resources and requests more efficiently.

This project is developed as a software-based disaster management solution without the use of AI/ML or additional hardware.
